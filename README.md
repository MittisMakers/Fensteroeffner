# Deutsch

## Was ist der Fensteröffner?

Das Gerät wird an der Wand und am Fenster montiert. Nach dem Setup mit der Arduino IOT Cloud kann man das Fenster dann über eine App mittels Dashboard und über Sprachassistenten wie Alexa und Google Assistant öffnen und dies ebenfalls in Routinen integrieren. 

## Entstehungsgeschichte

Wir sind zwei Studenten aus dem ingenieurswesen und der Informatik. Zusammen wollten wir ein Projekt erstellen, das unsere Fähigkeiten fördert und und zudem auch noch nützlich ist. Das Fenster automatisiert öffnen und schließen, um die deutsche Gewohnheit des Lüftens zu vereinfachen? Das klang nach einer guten Idee. Mit viel Arbeit, einem 3D-Drucker und dem Wissen, das wir aus Studium und Freizeit gewonnen haben, konnten wir dieses Projekt umsetzen.

# English

## What is the Window opener?

The device is mounted on the wall and window. After setting it up using the Arduino IOT Cloud, the device can be controlled by an app via the dashboard or by using smart assistants like Google Assistant or Alexa.

## Origin Story

We are two students originating from the fields of engineering and computer science. Together, we wanted to create a project for improving and developing new skills. Automating the german habit of “Lüften”, which is regularly opening the window for letting fresh air in? Sounds Great! With lots of work, a 3D-printer and the knowledge we gained from university and our freetime, we were able to make this project reality.

## Requirements

We have developed or improved the following skills during this project:

- soldering
- 3D-modelling
- 3D-printing
- Arduino programming language
- usage of Arduino IOT Cloud

## Arduino IOT Cloud

- create a new thing
- create the following variable:
    ![image](https://github.com/user-attachments/assets/196898c0-11e9-4ed1-90d0-56e5169d052e)
- fill out your secrets in the file `ThingProperties.h` using the Sketch Secrets tab
- Upload the sketch to your microcontroller
